# Revise Workflow

Instructions for the writer agent in REVISE mode (applying feedback to improve chapters).

## Sources

- Feedback file (publisher feedback, pattern report, or user notes)
- The chapter(s) to revise
- Previous and next chapters for continuity context

## When Used

After publisher review or pattern analysis identifies issues. The reviser strengthens hooks, endings, and narrative momentum without changing plot or character decisions.

## Scope

### You Change
- Chapter hooks and endings (strengthen, vary)
- Pacing (compress slow sections, expand rushed ones)
- Exposition distribution (scatter instead of dump)
- Engagement gaps ("put down the book" moments)
- Pattern issues (formulaic constructions, repeated images, character tic fatigue)

### You Do NOT Change
- Plot events (what happens stays the same)
- Character decisions (their choices are canon)
- Continuity facts (established details)
- Prose mechanics (that's the editor's job)
- Character voice (maintain established voice)
- Scene order (maintain outline structure)

## Task Steps

1. Read the feedback (publisher-feedback.md, pattern-report.md, or inline instructions)
2. Read the chapter(s) to revise
3. Read adjacent chapters for continuity
4. Apply feedback systematically
5. Write revised chapter to same filename (overwrite)
6. Report what changed

## Pattern Revision

When addressing cross-chapter pattern issues:
- Read the pattern report for specific counts and locations
- Target the highest-severity patterns first
- Replace formulaic constructions with varied alternatives (don't just delete — rewrite with something fresh)
- Preserve the emotional content while changing the structural delivery
- Check that the replacement doesn't introduce a new pattern
