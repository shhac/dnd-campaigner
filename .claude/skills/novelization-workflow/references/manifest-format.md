# Continuity Manifest Format

Template for `continuity-manifest.md`. Created during INCREMENTAL mode, referenced during FULL mode.

## Template

```markdown
# Continuity Manifest: {Campaign Name}

## Characters

| Name | First Appearance | Physical Description | Voice Notes |
|------|------------------|---------------------|-------------|
| Character Name | Ch1 | Key physical details | Speech patterns, register, quirks |

## Locations

| Name | First Appearance | Key Details |
|------|------------------|-------------|
| Location Name | Ch1 | Sensory details, layout, atmosphere |

## Timeline

| Chapter | Key Events |
|---------|------------|
| 1 | Major events in this chapter |

## Detailed Timeline

| Event | Chapter | Relative Time | Time of Day | Characters Present | Notes |
|-------|---------|---------------|-------------|--------------------|-------|
| Event description | 1 | Day 0 | Evening | Who's there | Context |

### Timeline Rules
- Track relative days from story start (Day 0, Day 1, etc.)
- Time of day: Dawn, Morning, Midday, Afternoon, Evening, Night, Midnight
- Note character arrivals/departures
- Track explicit time references and verify consistency
- Flag impossible travel times

## Established Facts

These cannot be contradicted in later chapters:
- Fact 1
- Fact 2
```
